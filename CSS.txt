26 ---	Resetting default margins and padding
	Khi bạn tạo một tệp HTML đơn giản (chưa viết dòng CSS nào), 
	các phần tử như tiêu đề <h1>, đoạn văn <p>, danh sách <ul> 
	đã tự có khoảng cách xung quanh
	
	Đó là do các trình duyệt (Chrome, Safari, Firefox...) 
	tự động thêm sẵn margin và padding mặc định

	Vấn đề: Mỗi trình duyệt lại có bộ quy tắc mặc định hơi khác nhau,
	khiến giao diện trang web của bạn hiển thị không đồng nhất trên các trình duyệt khác 
	
	<!--A simple reset-->
	* {
	    margin: 0;
	    padding: 0;
	}
	
	<!--A common foundation-->
	*,
	*::before,
	*::after {
	    box-sizing: border-box;
	}
	
27 ---	CSS box sizing
	
	+----------------------------------------------------------+
	|							   |
	|		+-------------------------+		   |
	|  left padding	|      content width	  |  right padding |
	|      20px	|	   158px	  |       20px	   |
	|      		+-------------------------+		   |
	|							   |
   left border						     right border
       1px							  1px
        |							   |
        +----------------------------------------------------------+
			actual render wide = 200px
			
	By default:
				box-sizing: content-box;
	This means:
				width represents the content width.
	For example:
				.box {
				    width: 200px;
				    padding: 20px;
				    border: 1px solid black;
				}

	With the default content-box:

				content = 200px
				padding = 20px + 20px
				border  = 1px + 1px

				actual width = 242px

40 ---	Reponsive design
	A website should adapt to different screen sizes.

	One important tool is the media query:

	@media (max-width: 768px) {
	    .container {
		flex-direction: column;
	    }
	}

	Meaning:

	Apply these styles when the viewport width is 768px or smaller.

	Example:

	.container {
	    display: flex;
	}

	@media (max-width: 768px) {
	    .container {
		flex-direction: column;
	    }
	}

42 ---	Psuedo-elements
	Pseudo-elements are different from pseudo-classes.

	Pseudo-class:

	:hover

	Pseudo-element:

	::before
	::after

	Example:

	.title::before {
	    content: "★";
	}

	This creates generated content before the element's content.

	Common pseudo-elements:

	::before
	::after
	::first-letter
	::first-line
	
43 ---	CSS Cascade
	CSS's called Cascading Style Sheets because multiple rules can apply to the 1 element

	The final style is determined by several factors, including:

	importance
	specificity
	source order
	inheritance

	A useful simplified mental model is:

	!important
	↓
	specificity
	↓
	later rule when specificity is equal

	Do not think of CSS as simply:

	"The last rule always wins."

	That is incorrect.
	
44 ---	Inheritance
	Some CSS properties are inherited from parent elements.

	Example:

	body {
	    color: blue;
	}

	A child paragraph will normally inherit the text color:

	<body>
	    <p>Hello</p>
	</body>

	The <p> becomes blue unless another rule overrides it.

	Not every CSS property is inherited.
	
45 ---	A basic CSS file struture
	A simple CSS file can be organized like this:

	/* Global / reset */
	*,
	*::before,
	*::after {
	    box-sizing: border-box;
	}

	/* Base styles */
	body {
	    margin: 0;
	    font-family: Arial, sans-serif;
	    color: #222;
	}

	/* Components */
	.button {
	    display: inline-block;
	    padding: 10px 20px;
	}

	/* Layout */
	.container {
	    display: flex;
	    gap: 20px;
	}

	/* Responsive */
	@media (max-width: 768px) {
	    .container {
		flex-direction: column;
	    }
	}
